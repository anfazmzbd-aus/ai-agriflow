# Codex starting instructions

1. Open the repository root in Codex and read `AGENTS.md`.
2. Inspect `git status`, `git log --oneline -5`, `docs/handoff/STATUS.md`, and `docs/handoff/TASKS.md`.
3. Run the baseline checks in README and compare this reconstructed tree to any existing AgentOS project before merging.
4. **Do not implement Task 2.3.2 yet.** First present the proposed `ExecutionResult[T]` design, invariants, files, tests, and acceptance criteria; request authorization to start.
5. After start authorization, implement only Task 2.3.2, run checks, report evidence, and request separate approval to commit.
6. After commit approval, commit, report SHA, and wait for separate authorization for the next task.
