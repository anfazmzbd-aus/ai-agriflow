# AgentOS AgriFlow

AgentOS AgriFlow is a versioned, production-oriented codebase for building reusable
agent framework components and agriculture-focused workflows.

This repository begins at `v0.1.0` with bootstrap structure, tooling, documentation,
examples, tests, and CI foundations.

Sprint 2 adds executable framework primitives for events, registries, tools, agents,
memory, models, workflows, adapters, telemetry, and runtime composition.
